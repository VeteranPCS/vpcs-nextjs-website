- Mobile adapts six selector items to a 3-column grid, tool cards to two columns (one at360), category cards to two, resource cards to one, journey and installation tiles to two. All sections remain available.

- Final review found 11 non-photo rows (header/divider/transition) at the top of the original hero crop. The revised native bounds start at y105; a new deployed filename avoids the image optimizer cache. The original crop remains only as the superseded provenance asset.

A chunk-gated browser regression reproduced the old visible-text/empty-state submission and now protects early typing without added timing delays.
