# Steph Resources implementation decisions

Source: `vpcs- webpage-update-resourses.pdf`, one desktop page. Reference render inspected at `/private/tmp/steph-resources.png`.

- Source hero is the recovered clean family/house/flag region, `/images/redesign/resources-hero-photo-region.png` (424×247; source bitmap bounds [440,105,864,352)). It contains no UI. Its limited crop does not fully preserve the child visible to the left of the service member in the source; this is the clean available region, not a claim of full-image recovery. The exact region is composed at the right of the hero with the shared flag asset and a navy overlay for text contrast. Asset provenance is recorded in the coordinator’s source manifest.
- The small hero eyebrow uses a brighter red (#ef5261) for readable contrast on navy; the shared red remains on white cards and buttons.
- Category counts derive from the published blog corpus, including secondary canonical categories. Buying a Home maps to Real Estate Insights; PCS Planning to PCS Help; Military Finance to Financial Guidance; VA Loan Help to VA Loan Help; Duty Station Guides to U.S. Military Bases. Counts and selected-category results share this mapping.
- The four featured photos are exact clean strips from the native 864×1821 source bitmap, excluding source red badges and text: packing (39,1045–218,1117), house (237,1045–417,1117), service member/child (437,1045–616,1117), signing (637,1045–823,1117). These do not replace article images in search results.
- Featured resources use real checklist, 2026 BAH, first duty station, and VA guide destinations. Fabricated source ratings are omitted. “Most Popular” becomes “Featured” because no popularity ranking data supports the label.
- Source “Download Checklist” becomes “View Checklist”: existing checklist is an article, without a checklist PDF. Free first-time homebuyer and VA loan downloads retain Salesforce guide capture contracts.
- Source “Veteran Discounts” becomes “Veteran Resources”: existing corpus verifies military businesses and resources but does not verify discounts. Partner strip says trusted resources rather than implying a partnership with every listed organization. Full existing trusted/life-resource corpus remains accessible via View All Resources, alongside employment, spouse resources, and sponsorship destinations.
- Installation tiles use six actual installation articles and their own corpus images rather than unrelated city photos from the mockup. All base guides links to the existing installation category.
- Bonus uses the shared existing tier helper. It expands on the `#move-in-bonus` permalink on phones and desktop; no unsupported home price is derived from BAH. BAH old hash remains a tool-card anchor with link to the dedicated calculator.
- Search lives in URL `q`, category in URL `category`, and all-resource browsing in `view=all`. Refresh, back, empty query, and reset use these same contracts. Analytics records only whether a query exists.
- Mobile adapts six selector items to a 3-column grid, tool cards to two columns (one at360), category cards to two, resource cards to one, journey and installation tiles to two. All sections remain available.

- Final review found 11 non-photo rows (header/divider/transition) at the top of the original hero crop. The revised native bounds start at y105; a new deployed filename avoids the image optimizer cache. The original crop remains only as the superseded provenance asset.
- Search is an uncontrolled native field initialized from the URL. Submission reads FormData, preserving text entered before hydration; only an actual query/category URL change updates its DOM value. A chunk-gated browser regression reproduced the old visible-text/empty-state submission and now protects early typing without added timing delays.
