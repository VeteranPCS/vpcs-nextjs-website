# WebDev build notes

Start with `npm run build:sandbox` using the committed lockfile. The active runtime uses Next.js **16.4.6** and PostCSS **8.5.23**. Next.js 16.4.3 introduced the fix for extensionless Google Fonts URLs in both bundlers. The follow-up runtime built successfully on Vercel. Four Roboto faces loaded and seven served WOFF2 files passed byte checks. [Next.js 16.4.3 release notes](https://github.com/vercel/next.js/releases/tag/v16.4.3)

Earlier Next.js 16.2.6 builds could fail when Google Fonts CSS used extensionless file URLs with query parameters. The November 25 build logged 27 Roboto errors in Turbopack, and webpack also failed during extension detection. The local fallback font fixture was used for historical functional checks during that failure. Verify current WebDev rendering and typography with the pinned normal build. [Next.js issue #99114](https://github.com/vercel/next.js/issues/99114)

When using a custom port, set `NEXT_PUBLIC_API_BASE_URL` to the same exact loopback origin for the build and `start:sandbox`. The artifact records that origin, and the launcher checks it before startup.

## Baseline defects found in browser verification

- The Colorado fixture area appears in `GET /api/v1/areas?state=CO`. That endpoint returns `vpcs-webdev-test-webdevinitial20261125-area`, which produces `404` with `No agent found for area` when passed to `GET /api/v1/states/colorado/area-agent`. The lookup returns the expected fixture agent and contact URL when given `vpcs-webdev-test-webdev-initial-20261125-area`. The existing coverage slug generator strips hyphens within names and the existing agent lookup preserves them as separators. The Agent Finder falls back to the generic state contact URL on this response. The Colorado partner cards link directly to their selected partner forms.
- `/impact` displays the sandbox totals and logs React hydration error `#418` in Chromium on desktop, tablet and mobile. `WearBlueSection.tsx` wraps a rich-text block in a paragraph, resulting in nested paragraphs in the server-rendered HTML. The browser parser restructures that markup before React hydrates it. [WearBlueSection.tsx](../components/Impact/WearBlueSection/WearBlueSection.tsx)
- On `/agents` and `/lenders`, the fixed header covers the top 32 pixels of each directory heading at 1440 pixels wide and the top 16 pixels at 820 and 390 pixels wide. The fixture rows remain visible and link to Colorado. The directory heading layout and site header spacing match the baseline source. The hosted runner logged six heading clips and three Impact `#418` occurrences across the three viewports as baseline diagnostics.
- One existing lender portrait has JPEG bytes at a `.webp` path. The hosted image bytes match the repository asset.
